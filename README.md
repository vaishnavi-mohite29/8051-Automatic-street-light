# Automatic Street Light System - 8051

Automatic ON/OFF street light based on ambient light using LDR sensor and 8051 Microcontroller.

## Components Used
- AT89S52 Microcontroller
- LDR Sensor
- Relay Module
- Aryabhatta Development Board

## How it Works
1. LDR senses ambient light
2. Day time = Light OFF
3. Night time = Light ON automatically

## Tools Used
- Keil uVision
- Embedded C
